# Pet-project_laptops_analysis
Анализ ассортимента ноутбуков 

Бизнес-цель проекта:
Определить оптимальные конфигурации ноутбуков для ассортимента интернет-магазина электроники. Сформировать алгоритм решения по включению или исключению моделей. Выделить ключевые инсайты позволяющие выбирать оптимальные модели не входящие в датасет для включения в ассортимент. 

Данные:
Источник: датасет Flipkart (laptops.csv).
Исходный размер: 984 строки, 12 признаков.
Размер после очистки: 514 строк, 10 признаков.
Целевые метрики: rating, price(in Rs.).

Стек:
Python 3.10, pandas, numpy, matplotlib, seaborn, scipy, scikit-learn.

Этапы проведенного анализа:
Очистка данных: удаление нерелевантных колонок, строк с пропуском rating и полных дубликатов.
Feature engineering: парсинг признаков RAM, Storage, Processor, Brand, OS из текстового формата.
Сегментация цен методом Дженкса: budget (<50 000 Rs), mid (50 000–100 000 Rs), premium (>100 000 Rs).
Корреляционный анализ (Spearman): выявление драйверов рейтинга.
Построение изотонической кривой для оценки соотношения цены и качества.

Ключевые выводы (корреляция с рейтингом):
Цена (r = 0.432) и бренд (r = 0.364) — главные факторы.
Объем RAM (r = 0.347) — самая важная техническая характеристика.
Процессор (r = 0.228) и OS (r = 0.195) — имеют умеренное влияние на пользовательский рейтинг.
Диагональ экрана (r = 0.062) и объем накопителя (r = 0.022) — не влияют на рейтинг.

Логика рекомендаций по ассортименту:

На первом этапе:
Базовый порог рейтинга: >= 4.3 (медианное значение).

Итого после Spearman:
Сегментация цен методом Дженкса: budget (36.4% ассортимента), mid (46.5% ассортимента), premium ( 17.1% ассортимента).

"Хорошая цена" (рейтинг > 4.3 для premium сегмента и выше средней кривой для своей цены для остальных сегментов) — однозначно включить в асортимент.
"Рекомендуемые" (рейтинг > 4.3 для premium сегмента и ниже средней кривой для своей цены для остальных сегментов) — оставить для заполнения матрицы.
"Исключить" (рейтинг < 4.3 для premium сегмента и имеет рейтинг значительно ниже среднего для своей цены для остальных сегментов)  — исключить из ассортимента (модели с плохим соотношением цены и качества).
